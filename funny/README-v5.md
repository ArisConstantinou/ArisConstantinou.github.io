# The Reset Show v5

English fictional parody, hosted at /funny/.

## Motion
actors-v5.js draws two articulated vector puppets. Canvas graphics use no portrait bitmaps. Spine/torso, jaw, lips, teeth, tongue, eyelids and eyebrows change separately. Two-bone inverse kinematics keep elbows and wrists attached during clapping, chin-rest and shushing gestures. Motion follows game state; dialogue has manual next-bubble controls.

Motion off honors reduced-motion by default. Sound uses synthetic cartoon effects, never voice cloning. No AI calls. Browser-only saves use a v5 key to avoid resuming into reordered questions.

questions-v5.js contains the new user-written opening (five themes, six rounds including a follow-up) plus nine existing scenarios. All scenario premises and dialogue are fictional, not a factual audit. Sources remain outside gameplay.
