Each source includes four unmodified 1K JPG maps: diffuse/albedo (`diff`),
OpenGL tangent-space normal (`nor_gl`), roughness (`rough`), and displacement
height (`disp`). The files are hosted with the application; runtime rendering
does not call the Poly Haven API. The official API was used to discover the
download URLs. `sources.json` records each original URL, byte count, and MD5
checksum verified after download.

Height maps affect actual mesh vertices when the editor enables relief on
sufficiently subdivided geometry. Normal maps provide additional fine surface
lighting detail; normal maps alone do not change an object's silhouette.

The editor's additional specialty materials are generated by the application's
original procedural material code. These are also the immediate loading fallback
for the scanned surfaces, and are automatically replaced when the local JPGs
finish loading.
