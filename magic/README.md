# MAGIC · Ο Εξόριστος Μάγος

Τρισδιάστατο παιχνίδι τηλεκίνησης για υπολογιστή και κινητό. Εισέβαλε στο κάστρο, χρησιμοποίησε αντικείμενα και εχθρούς ως όπλα, νίκησε τον Δεσμοφύλακα, πάρε το Μαύρο Σκήπτρο και επέστρεψε στη νότια πύλη. Τα θραύσματα αγοράζουν μόνιμες αναβαθμίσεις για τις επόμενες προσπάθειες.

## Χειρισμός

**Πάτησε πάνω στο αντικείμενο · Σύρε · Άφησε για ρίψη.** Η επιλογή γίνεται απευθείας πάνω στο συγκεκριμένο αντικείμενο ή στον εχθρό μέσα στον κόσμο. Όσο κρατάς πατημένο, το αντικείμενο ακολουθεί το δάχτυλο ή το ποντίκι στον αέρα. Το γρήγορο σύρσιμο καθορίζει την κατεύθυνση και δίνει περισσότερη δύναμη στη ρίψη.

| Ενέργεια | Υπολογιστής | Κινητό |
| --- | --- | --- |
| Κίνηση | W A S D ή βελάκια | Αριστερός μοχλός |
| Διάλεξε και σήκωσε | Κράτησε αριστερό κλικ πάνω στο αντικείμενο | Κράτησε το δάχτυλο πάνω στο αντικείμενο |
| Μετακίνησε ό,τι κρατάς | Σύρε με πατημένο το αριστερό κουμπί | Σύρε το δάχτυλο στον κόσμο |
| Ρίψη | Άφησε το αριστερό κουμπί | Σήκωσε το δάχτυλο |
| Άφημα χωρίς ρίψη | Q | ΑΦΗΣΕ |
| Δημιουργία πέτρας | R | ΠΕΤΡΑ |
| Ωστικό κύμα | F | ΚΥΜΑ |
| Εφόρμηση | Space | ΕΦΟΔΟΣ |
| Αντικείμενο ως ασπίδα | Κράτησε Shift ή δεξί κλικ | Κράτησε ΑΣΠΙΔΑ |
| Σκήπτρο / πύλη | E | ΧΡΗΣΗ |
| Παύση | Esc ή P | Κουμπί παύσης |

Ο αριστερός μοχλός λειτουργεί ανεξάρτητα: μπορείς να περπατάς με το ένα δάχτυλο και να μετακινείς ένα αντικείμενο με το άλλο. Η πέτρα που δημιουργείς εμφανίζεται μπροστά σου· πάτησέ τη και σύρε για να τη σηκώσεις και να τη ρίξεις. Το ΑΦΗΣΕ ενεργοποιείται όταν κρατάς αντικείμενο και το αφήνει χωρίς εκτόξευση.

Αν μια χειρονομία διακοπεί από παύση, αλλαγή εφαρμογής, ακύρωση της αφής από τον browser ή αλλαγή μεγέθους οθόνης, ακυρώνεται χωρίς ρίψη.

## Δημιουργία της έκδοσης δημοσίευσης

Απαιτούνται Node.js 22.12+ και npm. Από τον φάκελο `magic/_source`:

```sh
npm ci
npm test
npm run test:physics
npm run build
```

Το build δημιουργεί πρώτα πλήρη προσωρινή έκδοση στο `_source/.release`. Κατόπιν παράγει το `sw.js` με λίστα των runtime αρχείων και όνομα cache από το περιεχόμενό τους. Μόνο μετά την επιτυχή ολοκλήρωση αντιγράφει την έκδοση στον φάκελο `magic`. Αφαιρεί αποκλειστικά τον παλιό φάκελο των παραγόμενων bundles `magic/engine`. Τα αρχεία πηγής και το README διατηρούνται. Η `.release` δεν αποθηκεύεται στο git.

Η έκδοση που δημιουργείται λειτουργεί από το `/magic/` του υπάρχοντος GitHub Pages repository. Όλα τα URLs των runtime αρχείων είναι σχετικά. Η τελική δημοσίευση γίνεται με commit και push των αλλαγών του φακέλου `magic` στο repository.

## Προσθήκη στην αρχική οθόνη και offline

Το manifest περιλαμβάνει εικονίδια, σχετικό `start_url` και σχετικό `scope`, ώστε να μπορεί να προστεθεί ως εφαρμογή όπου το υποστηρίζει ο browser. Απαιτείται αρχική πλήρης φόρτωση με σύνδεση και επιτυχής εγκατάσταση του service worker πριν από χρήση offline.

Το service worker αποθηκεύει την αρχική σελίδα, τα bundles, τα εικονίδια και τα μοντέλα. Για πλοήγηση δοκιμάζει πρώτα το δίκτυο και διαθέτει την αποθηκευμένη αρχική σελίδα ως fallback. Τα runtime assets διαβάζονται πρώτα από την cache. Ο χειρισμός περιορίζεται σε GET αιτήματα του ίδιου origin μέσα στο scope του MAGIC. Η αναβάθμιση καθαρίζει αποκλειστικά παλιές caches του MAGIC στο ίδιο scope.

Η πρόοδος αποθηκεύεται τοπικά στον browser. Δεν υπάρχει συγχρονισμός λογαριασμού· η διαγραφή δεδομένων του site αφαιρεί και αυτή την πρόοδο.

- `_source/src/main.js`: γύρος παιχνιδιού, μάχη, φυσική και σύνδεση συστημάτων.

Τα επιλεγμένα μοντέλα και animations προσαρμόστηκαν για το παιχνίδι. Η αρχική άδεια περιλαμβάνεται στο `models/LICENSE-KayKit.txt`, ενώ η προέλευση και οι μετατροπές καταγράφονται στο `assets-credit.json`. Το εικονίδιο ρούνου σχεδιάστηκε ως SVG για το MAGIC.

## Κατάσταση ελέγχων

Έχουν γίνει έλεγχοι κώδικα και δοκιμές λογικής, συμπεριλαμβανομένων ελέγχων μοντέλων και φυσικής. Ο χειρισμός ελέγχεται με πραγματικούς UI handlers σε Node και προσομοιωμένα pointer events: ταυτόχρονη κίνηση/σύρσιμο, μοναδική ρίψη στην απελευθέρωση και ακύρωση χωρίς ρίψη. Δεν έχει γίνει οπτική ή διαδραστική επιβεβαίωση σε browser ή πραγματικό iPhone σε αυτή τη συνεδρία. Η τελική εμφάνιση, οι επιδόσεις στη συσκευή και η εγκατάσταση/offline συμπεριφορά χρειάζονται επιβεβαίωση σε πραγματικό browser.
