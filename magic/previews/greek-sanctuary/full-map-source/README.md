# MAGIC connected Greek and Gothic map source

This source builds the connected fourteen-room campaign, bridge, three secrets, three upper floors and monumental temple precinct. Twelve physical wings create L/T/stepped room footprints. Greek and Gothic regions use different masonry, windows, columns, portal frames and room surfaces. The Parthenon-inspired ruin has8x17historical column positions with missing/broken members, twenty-flute Doric shafts, interrupted entablatures and a69.5x30.9m stylobate. It is a gameplay adaptation with widened HEARTH routes, not an exact archaeological reconstruction.

Pinned tools: Three.js0.180.0, Cannon-es0.20.0 and Vite7.1.7. Run from this folder: `npm ci --prefix game` if locked dependencies are absent, then `node build.mjs --monument`. No dependency install occurs when playing. Preserve the project's one strict localhost port5173. The older default and --architecture variants remain available.

The build writes site/full-map-monument.htm and hashed engine assets. Existing models/, greek-sanctuary/, environment-b/, threshold-materials/, icons/ and statues/ runtime directories must accompany that entry. Statue exports may live in statues/exports, otherwise the builder reuses the adjacent ../statues/models files. The full local source also retains original scans, editable Blender preparation and licence/provenance records; those large files are excluded from this hosted snapshot.

Run the pure rules with `node --test navigation.test.js clearance.test.js collision-box.test.js pressure-snap.test.js architecture-plan.test.mjs monument/*.test.mjs`. Browser QA scripts and full-resolution before/after images remain in the local deliverable; lean release metrics accompany the public preview. Passing per-scenario tests is distinct from uninterrupted campaign proof.

Actual body collision and support heights drive mage/HEARTH movement. Camera-relative WASD remains stable after orbit rotation. Obstructing wall units disappear with their entire decoration; stairs hide only obstructing three-tread sections. Single/double fenced pressure trays retain indestructible telekinetic weights; other passages are open or use burnable doors. Gothic leaves reuse the existing timber kit with iron hardware and moulded stone jambs.

Caryatid (Daniel Pett, CC BY4.0), Venus de Milo (SMK/Shaderbytes, CC0) and Artemision Zeus/Poseidon (SMK, CC0) retain source-derived fracture geometry and real physical marble debris. See statues/LICENSES.md and provenance. The Artemision replica and existing Sanctum encounter occupy the raised temple cella. Goliath assembly supports the nested GLTF stone hierarchy, cancellation restoration and actual floor heights for navigation and planted feet.

Historical plan/reference: https://www.ysma.gr/en/monuments/parthenon/ . Greek/Gothic architectural direction was selected by the user; screenshots are actual game output.
