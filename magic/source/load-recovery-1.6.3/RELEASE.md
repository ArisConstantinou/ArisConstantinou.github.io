# MAGIC 1.6.3: recover slow initial downloads

One initial statue request taking longer than45 seconds previously failed the whole boot. The release uses a30-second inactivity deadline refreshed by arriving bytes, up to3 attempts and a180-second total limit per asset. It displays downloaded bytes and retries, and keeps the existing retry button for a failed connection. Required external glTF buffers and images use the same transport. Two large model loads/decode jobs run concurrently, with one destination buffer for known-size uncompressed responses.

Low quality allocates and compiles its screen rendering path. The existing high-quality pipeline is created when selected. Full scene rendering starts after boot completes. Models, textures, animations, map, enemies, physics and quality settings retain their original content.
