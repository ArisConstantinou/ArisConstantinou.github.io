# FROG 4.3.17

Mobile controls now use COD-style swipe look: the left stick moves, dragging the free right side rotates and aims, and a separate movable82px Fire button shoots. Holding a stationary look contact stops rotation; repeated swipes allow unlimited horizontal turns. Dragging the held Fire button also aims, enabling two-thumb movement/aim/fire. Independent contacts release without cancelling another control. Pause, disable, cancellation and view changes clear held fire.

The special catapult direction/power pad remains available while mounted. Existing manual/explicit-auto fire preferences, control positions, saved rounds, desktop controls, menu artwork, arena geometry and automatic updates are retained.

Validation:1256 source tests; production build; real browser touch sequences in390x844 and844x390; independent three-contact movement/look/fire,360-degree swipes, stop/release/cancel, two-thumb Fire drag, pause/resume, layout editing, overview, kick and catapult controls; desktop WASD/camera/mouse. Headless RTX5080 measurements are engineering checks, not physical-phone performance proof.
