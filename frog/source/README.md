# FROG 4.3.0 — Η τελευταία αποθήκη

[Παίξε το FROG 4.3.0](https://arisconstantinou.github.io/frog/?v=4.3.0)

Ένας βάτραχος, μύγες για πυρομαχικά και μία αποθήκη που πρέπει να προστατεύσεις. Κερδίζει ο τελευταίος βάτραχος με άθικτη αποθήκη.

## Ο γύρος

1. Όλοι ξεκινούν μέσα στο δικό τους καταφύγιο με **0 μύγες**. Η κοινή αντίστροφη μέτρηση **20 δευτερολέπτων** αρχίζει αμέσως.
2. Η άθικτη αποθήκη δίνει **απεριόριστες μύγες**, τις οποίες συλλέγεις αυτόματα από κοντά. Στο στόμα μεταφέρεις έως **60**. Οι αντίπαλοι ακολουθούν τους ίδιους κανόνες.
3. Μετά την προετοιμασία αρχίζει η μάχη. Κάθε βολή καταναλώνει μία μύγα. Όταν αδειάσεις, γύρνα στην αποθήκη ή πλησίασε ένα εξωτερικό σμήνος. Τα εξωτερικά σμήνη έχουν συγκεκριμένο διαθέσιμο απόθεμα και αναπληρώνονται σταδιακά.
4. Έξι εύστοχες μύγες προκαλούν ζάλη. Τρία επιπλέον χτυπήματα μέσα στο περιθώριο ζάλης ολοκληρώνουν το knockout. Η κλωτσιά δημιουργεί χώρο από κοντά και λειτουργεί χωρίς πυρομαχικά.
5. Το knockout σε στέλνει πίσω στο δικό σου καταφύγιο μετά από **12 δευτερόλεπτα**, με άδειο στόμα, όσο η αποθήκη σου παραμένει άθικτη. Αυτό το διάστημα αφήνει ένα πρακτικό περιθώριο επίθεσης στην αποθήκη.
6. Πέρασε από την είσοδο μιας αντίπαλης βάσης και πλησίασε την αποθήκη. Κράτησε την ενέργεια καταστροφής για **10 συνεχόμενα δευτερόλεπτα**. Εμφανίζονται πρόοδος και χρόνος που απομένει, ενώ ο βάτραχος δουλεύει με τα μπροστινά πόδια.
7. Εύστοχο χτύπημα στον εισβολέα, απομάκρυνση, βολή, κλωτσιά ή απελευθέρωση του κουμπιού διακόπτουν την καταστροφή και μηδενίζουν την πρόοδό της. Για άμυνα, χτύπησε αυτόν που καταστρέφει την αποθήκη σου.
8. Η καταστροφή της αποθήκης αποκλείει τον ιδιοκτήτη της. Η τελευταία άθικτη αποθήκη κερδίζει τον γύρο.

## Βάσεις και κάλυψη

Κάθε καταφύγιο και κάθε καταπέλτης περιβάλλεται από πραγματικά τείχη με **μία ανοικτή είσοδο**. Οι βάτραχοι, οι βολές και ο ανεφοδιασμός υπακούν στα ίδια εμπόδια. Οι αντίπαλοι χρησιμοποιούν τις κανονικές εισόδους για επιδρομή, άμυνα και ανεφοδιασμό.

Στις συστάδες δέντρων τα άλματα γίνονται πιο αργά και ο βάτραχος κρύβεται από τον μακρινό αυτόματο εντοπισμό. Οι επιθέσεις αποκαλύπτουν προσωρινά τη θέση του, ενώ ένας αντίπαλος πολύ κοντά μπορεί να τον αντιληφθεί. Το κοντινό φύλλωμα, η στέγη και τα τείχη που εμποδίζουν την κάμερα γίνονται διαφανέστερα για να φαίνεται ο παίκτης, χωρίς να αλλάζουν οι συγκρούσεις.

Ο χάρτης παραμένει ανοικτός και δείχνει αποθήκες, ανοίγματα των περιβόλων, καταπέλτες, σμήνη και κάλυψη. Οι τρεις έγχρωμες ενδείξεις επάνω δείχνουν ποιες αποθήκες παραμένουν άθικτες. Όταν δέχεσαι εισβολή, εμφανίζεται προειδοποίηση με τον χρόνο που απομένει.

## Χειρισμός

| Ενέργεια | Υπολογιστής | Κινητό |
| --- | --- | --- |
| Άλματα | WASD ή βέλη | Αριστερό χειριστήριο |
| Στόχευση | Ποντίκι | Δεξί χειριστήριο |
| Εκτόξευση μυγών | Κράτημα αριστερού κλικ | Ξεχωριστό κουμπί **ΠΥΡ** |
| Συλλογή | Αυτόματα κοντά στην αποθήκη ή σε σμήνος | Αυτόματα |
| Κλωτσιά | Q | Κουμπί **ΚΛΩΤΣΙΑ** όταν υπάρχει κοντινός αντίπαλος |
| Καταστροφή αποθήκης | Κράτημα E κοντά στην εχθρική αποθήκη | Κράτημα του κουμπιού **ΚΡΑΤΑ · 10″** |
| Είσοδος/έξοδος καταπέλτη | E κοντά στον δικό σου | **ΧΡΗΣΗ / ΕΞΟΔΟΣ** |
| Εκτόξευση πέτρας | Αριστερό κλικ | Δεξί χειριστήριο για κατεύθυνση/ισχύ και κουμπί **ΠΕΤΡΑ** |
| Κάμερα | C ή κουμπί κάμερας | Κουμπί κάμερας |
| Παύση | Escape ή Ⅱ | Ⅱ |

Η κύρια κάμερα παραμένει **πίσω από τον βάτραχο**. Διατηρείται και η κεντραρισμένη κάτοψη. Η κατεύθυνση μιας συνεχόμενης κίνησης παραμένει σταθερή καθώς ακολουθεί η κάμερα, ώστε ένα κρατημένο χειριστήριο να μην προκαλεί κυκλική κίνηση.

Το δεξί χειριστήριο χρησιμοποιείται για στόχευση και το ξεχωριστό κουμπί για βολή. Πάτησε **ΘΕΣΕΙΣ** μέσα στη μάχη, σύρε την κίνηση, τη στόχευση και τη βολή εκεί που σε βολεύουν, και πάτησε **ΤΕΛΟΣ**. Ο γύρος και ο ήχος περιμένουν όσο αλλάζεις θέσεις. Οι θέσεις διατηρούνται ξεχωριστά για όρθια και οριζόντια οθόνη. Η **ΕΠΑΝΑΦΟΡΑ** επαναφέρει την αρχική διάταξη.

## Καταπέλτες και επιπτώσεις

Ο καταπέλτης είναι ξεχωριστός σταθερός μηχανισμός που χειρίζεται ο βάτραχος με τα μπροστινά του πόδια. Επαναφορτώνει αυτόματα σε τρία δευτερόλεπτα και δεν καταναλώνει τις μύγες του στόματος.

Η πέτρα ακολουθεί παραβολική τροχιά, με προειδοποίηση στο σημείο πρόσκρουσης. Η κεντρική πρόσκρουση προκαλεί μεγαλύτερη ζημιά και ώθηση από την άκρη. Τα τείχη προστατεύουν από την πλευρική εξάπλωση της πρόσκρουσης. Ο αντίπαλος τινάζεται προς τα πάνω και πίσω και προσγειώνεται με πιτσίλισμα. Τα τρισδιάστατα κύματα, σταγονίδια, ήχος και αντιδράσεις παγώνουν με την παύση.

## Αποθήκευση

Η συνέχεια κρατά τις μύγες, την κατάσταση των αποθηκών και την πρόοδο του γύρου. Μια μισοτελειωμένη καταστροφή διακόπτεται κατά τη φόρτωση. Οι προηγούμενες αποθηκεύσεις arcade μεταφέρονται στους νέους κανόνες, με ξεχωριστή διατήρηση του αρχικού αντιγράφου στον ίδιο browser. Τα δεδομένα άλλων παιχνιδιών ή παλιότερων λειτουργιών δεν αλλάζουν.

## Ανάπτυξη και επαλήθευση

Ο πηγαίος κώδικας είναι στο `frog/source`. Το production build βρίσκεται στο `frog` για το υπάρχον GitHub Pages.

```sh
npm ci
npm test
npm run build
python3 -m http.server 4173 --directory dist
node qa/arcade-430.mjs
```

Το τελευταίο βήμα απαιτεί Playwright και Chromium. Η διαδικασία περιέχει πραγματικά συμβάντα πληκτρολογίου, ποντικιού και αφής σε Chromium, μαζί με καθορισμένα βήματα προσομοίωσης για χρονισμούς και σενάρια μάχης. Η αποτύπωση 3D εικόνας και τα κινητά μεγέθη ελέγχονται στον browser. Αυτό δεν αποτελεί μέτρηση FPS ή φυσική δοκιμή σε iPhone/Android.
