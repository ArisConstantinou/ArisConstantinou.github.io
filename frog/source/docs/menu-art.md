# Start-menu illustration

Asset: `public/art/menu-plaque-v1.png`.

Created for the 2.1.3 menu with built-in image generation, then copied unchanged into the project. Original image: 2172 × 724 pixels, RGBA with genuine transparency. Labels and icons are accessible HTML/SVG overlays; animation comes from `src/start-screen.css`.

## Generation prompt

Use case: stylized-concept.

Asset type: one production-ready illustrated button background for a cinematic frog-and-creek game menu.

Primary request: A single tactile horizontal game UI button/plaque, approximately 3:1 aspect ratio, front-facing with almost no perspective. Chunky sculpted elongated water-lily/jade-green plaque with a deep forest-green smooth inset center, hand-carved dark driftwood edge, and restrained warm-gold beveled trim. Subtle moss and dewdrops only at the outer ends. Polished dimensional highlights and soft contained shadow. Natural premium game asset, realistic materials with art-directed clarity.

Composition: The one button fills nearly the entire wide canvas with modest transparent padding. Center is broad, smooth, dark, empty and very readable for runtime text and a runtime icon. Clean distinct silhouette and substantial rim, readable when displayed at about 400 by 130 pixels.

Text: none. Absolutely no words, letters, numbers, logo, glyphs or icon.

Constraints: Actual transparent background; isolated button asset only. No background scenery, frogs, characters, props outside the button, screenshot, mockup, contact sheet, multiple variants or baked-in UI labels. No rectangular background behind the cutout.
